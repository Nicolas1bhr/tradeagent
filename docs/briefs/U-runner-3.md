**Two bounds I introduced, stated rather than hidden.** `Backtest.MaxTracedBars` is 200,000 bars (about 139 days of minutes): a run holds one trace event per bar and the trace is what every figure is computed from, so a longer window HALTS with a defined fault naming `--from`/`--to` and "a year is four runs of a quarter each" rather than truncating — **a twelve-month backtest is therefore not one request in this build**. And `ExecutionModel` refuses a fee or a slippage above 0.05 and capital above a billion, because `--fees 0.1` from an agent that meant a tenth of a per cent would lose the run on the declaration rather than on the strategy; the refusal says which reading it took.
