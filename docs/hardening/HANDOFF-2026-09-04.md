## 1. Structure that worked (keep it)

- **Manager on Fable writes no code.** Every build/verify leg is an Opus `general-purpose` agent; Codex runs as a
  background `codex exec` (`gpt-5.6-sol`, `-s read-only`, `-o` to a record file, `< /dev/null`). Hard cap: **2 heavy
  Claude legs at once**; the usage window empties in ~4 h of two-leg work regardless (EIGHT rate-limit kills this
  session), and **after a process restart the agent ids and the message channel are gone** — a killed leg is re-briefed
  from disk as a fresh agent, which works because:
- **Every leg's brief, bounce and Codex prompt is a file in `docs/hardening/briefs/`**, every leg checkpoints its
  record section in `docs/hardening/records/<unit>.md` in the MAIN worktree as it goes (the manager commits), and builders
  commit per finding — so a kill loses at most the in-flight item. Codex raw outputs are `records/codex-<unit>-r<n>.txt`.
- **One worktree per leg** under `~/Projects/ai-trading-software-for-mihael-worktrees/` (builders on the branch, verifiers
  and Codex detached at the sha); verifiers keep their probes on `u*-verify-r<n>-probes` branches (14 exist — reuse them).
- **The Windows box is a one-toucher resource**: explicit manager grant to ONE leg, push → prove the tree by SHA-256 of
  changed files + the `.cs` count → run in one ssh session → re-hash. Two legs on the box at once replaced each other's
  tree once and every on-box figure of that day was withdrawn.
- **Gates:** `dotnet build TradeAgent.sln --no-incremental` (an incremental "0 warnings" hid a new warning) + the full
  suite with output to a file; test-method-name diff after every structural edit (a deleted test cannot fail — it
  happened three times); a SURVIVED mutant is evidence only if the test count moved; findings are inputs, never
  auto-applied, refutations written with the reason; §9.10 — after a class recurs, change the structure, not the instance.
