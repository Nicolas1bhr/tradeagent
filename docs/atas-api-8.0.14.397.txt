# ATAS 8.0.14.397 public API surface — reflection dump
#
# WHY THIS IS IN THE REPOSITORY. Every ATAS identifier the bridge uses was checked against this
# before it was compiled — 125 of them — and the three ATAS lifecycle hooks were confirmed by the
# compiler because a dump carries public members only. It is the difference between writing against
# the API and writing against a memory of it. It existed nowhere but a session scratchpad under
# /private/tmp, which macOS clears, so the artefact behind every ATAS decision in this codebase was
# one reboot from gone.
#
# There is no ATAS NuGet package and no published reference documentation of this depth; the vendor's
# own docs render %APPDATA% wrong (trap 7) and predate this version.
#
# WHAT IT IS: public types and members only, from the four assemblies the bridge references. Names
# and signatures — no vendor code, no IL, no resources. It records NO attributes, so [Obsolete] does
# not appear here; CS0618 from a real build is the only source for that (trap 25).
#
# TO REGENERATE, on a Windows machine with ATAS installed, reflect over:
#   ATAS.Strategies.dll  ATAS.Indicators.dll  ATAS.DataFeedsCore.dll  Utils.Common.dll
# in "C:\Program Files (x86)\ATAS Platform". Keep the version in the filename: a dump that does not
# say which build it came from cannot settle an argument about a vendor upgrade.
#
