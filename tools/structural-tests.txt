# THE STRUCTURAL TESTS tools/precheck.sh runs before a CI dispatch (U-ci-precheck). One class per line: its full name, then why it is
# structural: it reads the source, the docs, the frozen contract, the schema or the type system, and starts no runner, no cell, no
# vendor and no clock-bound wait, so it fails the same way on every platform in seconds. Each line is a class whose red reached a full
# CI run in the window R31 D8 measured, or the guard of the same kind beside it.
